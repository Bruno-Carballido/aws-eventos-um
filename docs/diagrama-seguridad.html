Diagrama de seguridad

Sistema de inscripción y recordatorios para eventos · arquitectura ECS en us-east-1 · zonas de confianza, controles y debilidades conocidas

Controles activos

  • • Grupo de seguridad del ALB con solo el puerto 80 abierto.
  • • Grupo de seguridad de las tareas con solo el puerto 8000, desde el ALB.
  • • Tareas sin IP pública y sin NAT, sin ruta a Internet.
  • • Endpoints de VPC que aceptan solo el puerto 443 desde la VPC.
  • • DynamoDB cifra los datos en reposo por defecto.
  • • Correos de SNS solo a suscripciones confirmadas por el usuario.
  • • Imagen escaneada en ECR al subirla.

Debilidades conocidas

  • • El sitio en S3 se sirve por HTTP, sin HTTPS.
  • • El ALB atiende por HTTP, sin HTTPS.
  • • La API no tiene autenticación, así que el GET de inscripciones por correo es público.
  • • CORS abierto a cualquier origen.
  • • Sin WAF ni límite de tasa por ruta.
  • • El contenedor corre como root.
  • • LabRole compartido como rol de ejecución y de tarea.

Mejoras para producción

  • • HTTPS con certificado en el ALB, o CloudFront donde esté permitido.
  • • Cognito o autorizador JWT en la API.
  • • Un rol por función, con permisos mínimos.
  • • AWS WAF delante de la API.
  • • Usuario sin privilegios en el contenedor.
