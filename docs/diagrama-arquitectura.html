Sistema de Inscripción y Recordatorios para Eventos

Arquitectura serverless orientada a eventos — UM, curso de AWS

Flujo de inscripción

  • • 1-2 · El usuario abre el sitio en S3 y consulta eventos
  • • 3-5 · API Gateway invoca Lambdas sobre DynamoDB
  • • 6-7 · InscripcionCreada se notifica por SNS por email
  • • La API responde apenas se registra (async)

Recordatorios

  • • 8-9 · EventBridge dispara cada hora la Lambda
  • • Ventana de 24 h con flag anti-repetición
  • • 10 · Marca notificado en la tabla Eventos
  • • 11 · Fallos tras reintentos caen a la DLQ

Operación

  • • 12 · CloudWatch centraliza logs y errores
  • • IAM mínimo privilegio vía LabRole (Academy)
  • • Lambda fuera de VPC: sin ENIs ni NAT
  • • Escalado automático en todos los servicios
