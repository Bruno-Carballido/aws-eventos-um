Diagrama de red: Sistema de inscripción y recordatorios para eventos

Qué está expuesto a Internet, qué queda dentro de AWS y por dónde viaja el tráfico

Qué está expuesto

  • • S3 por HTTP. Sin HTTPS propio.
  • • API Gateway por HTTPS. Sin autenticación.
  • • SNS envía correos hacia Internet.
  • • El resto no tiene puntos de entrada públicos.

Por qué sin VPC

  • • Ningún recurso del proyecto es privado.
  • • Sin VPC no hay subredes, NAT ni security groups que administrar.
  • • El control de acceso queda en IAM.

Si se usara VPC

  • • Subredes privadas en dos zonas.
  • • Endpoints de Gateway para DynamoDB y S3.
  • • Endpoints de interfaz para SNS y SQS.
  • • NAT solo si una función necesitara salir a Internet.
